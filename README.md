# 📊 Data Analysis Projects

This repository contains multiple **data analysis projects** exploring different datasets and insights.  
Currently, there are two active branches:  

- **cat_data_analysis** 🐱 → Analysis of cat-related dataset  
- **chess_data_analysis** ♟️ → Analysis of chess dataset  

---

## 🚀 Repository Structure

- **main** → Documentation, requirements, and overview  
- **cat_data_analysis** → Jupyter notebooks, scripts, and visualizations for cat data  
- **chess_data_analysis** → Jupyter notebooks, scripts, and visualizations for chess data  

---

## 🛠️ Tech Stack

- **Python 3.9+**  
- **Jupyter Notebook**  
- **Pandas / NumPy** → Data handling  
- **Matplotlib / Seaborn / Plotly** → Visualization  
- **Scikit-learn** → (if ML models are applied)  

---

## 📂 How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/pavansy6/data_analysis.git
   cd data_analysis
   ```

2. Create a virtual environment (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate   # On Linux/Mac
   venv\Scripts\activate      # On Windows
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Switch to the branch you want to explore:
   ```bash
   git checkout cat_data_analysis
   # or
   git checkout chess_data_analysis
   ```

5. Run the Jupyter notebooks:
   ```bash
   jupyter notebook
   ```
